NATURAL DISASTERS - Minecraft Java Edition 1.16.5 (Forge)

IMPORTANT: This is the mod's SOURCE PROJECT ZIP, not a ready-to-install .jar.
I could not compile/test a Forge jar in this environment. You need Java JDK 8 and
a ForgeGradle setup to build it.

10 disasters:
1 Tornado
2 Earthquake
3 Meteor Shower
4 Lightning Storm
5 Flood
6 Wildfire
7 Sandstorm
8 Blizzard
9 Volcanic Eruption
10 Sinkholes

Commands:
  /disaster help
  /disaster start 1
  /disaster start 3 20

Use cheats or operator permissions. Radius allowed: 5-30 blocks.
WARNING: Test in a COPY of your world. Some disasters create explosions, fire, lava,
water, or remove blocks.

Forge version targeted: 1.16.5-36.2.39.
